Photo & reference

Photograph your object flat on a surface next to a known-size reference. The reference corrects scale (and, for a rectangle, perspective too).

Drag the four handles onto the reference corners — the yellow edge is the top. Scroll to zoom, drag to pan, double-click to fit.

Drag the circle over the coin and its edge handle to the rim. A coin sets scale only — shoot straight down so there's no perspective. The object (largest shape) is traced; the coin is ignored.

Or import a drawing

Skip the photo — import an existing vector drawing straight into the trace. Units come from the file. (DWG isn't supported — export it as DXF from your CAD app.)

Trace & holes

Re-tracing replaces manual outline edits.

Straightens lens-bowed edges. Nudge until the paper's edges look straight, or let Auto read them. 0 = off.

Hole properties

Measure

Click a hole for ⌀ · two points for distance · point + edge for offset · two edges for angle (near-parallel edges also get the face-to-face gap) · an edge twice (or edge then empty space) for its length. Snaps to corners, midpoints and hole centres. Esc cancels.

Constraints

Pick one or two entities on the canvas (corner, edge, or hole), then apply. Constraints re-solve while you drag; the dashed ghost shows where geometry will land.

Selection

Ctrl/⌘-click points to multi-select, or Shift-drag a box around them. Drag any selected point to move the group; Delete removes them. Then clean up the selected run:

Live fillet — stays tangent as you edit the adjacent edges.

Project — save / move / load

Embedded views (like the Claude artifact) block file downloads. To move your work: Copy here → open the offline dist/2.5d-local.html (or a hosted copy) → Project → paste → Load from text. Corners, trace, holes and settings all transfer, so nothing needs re-tracing.
