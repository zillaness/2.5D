Blueprint drawing / photo → traced outline → printable solid

Photo & reference

Photograph your object flat on a surface next to a known-size reference. The reference corrects scale (and, for a rectangle, perspective too).

Drag the four handles onto the reference corners — the yellow edge is the top. Scroll to zoom, drag to pan, double-click to fit.

Drag the circle over the coin and its edge handle to the rim. A coin sets scale only — shoot straight down so there's no perspective. The object (largest shape) is traced; the coin is ignored.

Or import a drawing

Skip the photo — import an existing vector drawing straight into the trace. DXF/SVG carry their own units; for PDF you confirm the view and scale. (DWG isn't supported — export it as DXF; scanned PDFs need OCR, coming later.)

Project — save / move / load

Embedded views (like the Claude artifact) block file downloads. To move your work: Copy here → open the offline dist/blueprint-local.html (or a hosted copy) → Project → paste → Load from text. Corners, trace, holes and settings all transfer, so nothing needs re-tracing.

Outline library

Save the current outline (drawer, toolbox, tray…) to reuse it later — e.g. as a container shape for foam or Gridfinity layouts. Stored in this browser.
