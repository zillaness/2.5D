Shoot square-on (straight above, key flat), shoulder and cuts visible. Use Rotate/Mirror/Flip to orient it roughly level, bow to one side. A card behind the key is optional (see Scale).

Place a standard ID-card-sized rectangle behind the key. Because its real dimensions are known, the four corners let the app correct both scale and perspective skew — so even an off-square photo reads true. (Square-on with no card also works; scale then comes from the cut spacing.)

Cards have rounded corners, so don't aim the handles at the corners — line up the box's edges with the card's straight sides. The corners sit where those edges would meet.

  • Green = back edge: drag its two ends onto the blade's straight back (depth zero).
  • Red line per cut: drag into the valley — left/right onto the cut, up/down to its floor.

Red = height matches a depth cleanly. Orange = between two depths — nudge until it turns red.

Scroll to zoom, drag an empty area to pan — for precise placement.

Pick the matching blank up top first (e.g. BEST-A for a BEST A / DORMA key) so the right number of cuts appears.

—

The green line's arrow points to the tip; cut #1 is read from the bow end. If your key is the other way round, Flip reverses the reading.

⚠ Reading direction is per-keyway. This app numbers bow→tip. keygen uses the same bow→tip order for Schlage, so Schlage codes transfer directly. BEST/SFIC is the exception — it's numbered tip→bow — so reverse the code for BEST keys (in keygen or off a BEST spec sheet).

Know the code (from calipers or a locksmith)? Type it to skip the photo.

Engraved into the up-facing side of the bow (print that face up; the blade cuts stay flat on the bed). Leave blank for no label. Regenerate to apply.

Printed keys are fragile. Print it lying flat on the bed — the key face-down, cuts in the plane of the bed — in PETG, nylon, or resin. Treat it as an emergency spare, not a daily key. Only duplicate keys you're authorized to copy.

💡 Backup plan: the printed key is a working spare — but it's also a physical backup of the key itself. If you lose the original, a locksmith or a key-cutting kiosk can cut a fresh metal key straight from your 3D print (or just from the bitting code you decoded above — write it down). Keep the print or the code somewhere safe.
