Funny Looking Rock photograph a key → print a spare

← 2.5D

Key flat on a card (85.60 × 53.98 mm), shoulder and cuts visible. Use Rotate/Mirror/Flip to orient the key roughly level, bow to one side.

Auto-finds the card and drops a box on it; nudge any corner if it's off (85.60 × 53.98 mm). Scale updates live as you drag.

Three things to line up (see How this works below):

  • Shoulder line → the shoulder stop (where the blade meets the bow).
  • Back edge line → the straight back of the blade. This is depth zero.
  • Each red dot → drag into a cut's valley. Its height above the green line is that cut's depth. Slide left/right to line up the cut, up/down to set the depth.

Pick the matching blank up top first (e.g. BEST-A for a BEST A / DORMA key) so the right number of cuts appears.

How this works

Each red dot's height above the green back line is that cut's depth → a digit. Deep dot (near the back) = big number; shallow dot = small number.
